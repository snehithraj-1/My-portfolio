## 📌 Overview

This personal developer portfolio showcases modern web applications and AI-driven systems. Built to break beyond static websites, it features dynamic 3D rendering, interactive perspective tilt cards, a live interactive terminal emulator, and confetti celebration triggers.

---

## ✨ Features

- 🌐 **Real-Time 3D WebGL Core**: 60 FPS interactive rotating cyber core with 1,600+ floating particle nebula.
- 🔊 **Web Audio Synthesizer**: Offline synthesized hover clicks, navigation blips, and victory chords using the Web Audio API.
- 🎴 **3D Perspective Tilt Cards**: Mathematical mouse-tracking 3D card tilt with specular light reflection overlays.
- 💻 **Interactive Cyber Terminal**: Built-in interactive command terminal supporting commands (`help`, `skills`, `projects`, `contact`, `clear`).
- 📨 **Direct Background Email Dispatch**: Contact form with real-time validation and celebratory confetti.

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
